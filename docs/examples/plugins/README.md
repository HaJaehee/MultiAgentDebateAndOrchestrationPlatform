# 플러그인 예제

복사해서 바로 쓸 수 있는 예제입니다. 이 폴더에 있는 동안에는 앱이 읽지 않습니다.

| 파일 | 복사할 곳 | 보여 주는 것 |
| :--- | :--- | :--- |
| `strategies/consensus_voting.py` | `strategies/` | 라운드마다 발언 순서와 지침이 달라지는 토론 전략 |
| `host_tools/glossary.py` | `host_tools/` | 위험 등급을 밝혀 묻지 않고 실행되는 호스트 도구, 시스템 프롬프트 지침 |
| `host_tools/ticket.py` | `host_tools/` | 등급을 밝히지 않아 승인 카드가 뜨는 호스트 도구, 작업 공간에 쓰기 |

복사할 곳은 프로젝트 루트 기준입니다. 없으면 만듭니다. 복사한 뒤 서버를 다시 시작하고, 호스트 도구는 에이전트 카드의 `도구` 창에서 켭니다.

자세한 설명은 [플러그인 설명서](../../user_manual/03-core/11-plugins.md)에 있습니다.

> 플러그인은 앱과 같은 권한으로 도는 코드입니다. 내용을 읽고 신뢰하는 코드만 넣으십시오.

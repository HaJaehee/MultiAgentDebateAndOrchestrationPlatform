# 플러그인 예제

복사하여 바로 활용할 수 있는 토론 전략 및 호스트 도구 플러그인 예제 모음입니다. 이 디렉터리에 위치한 동안에는 애플리케이션에서 자동으로 로드되지 않습니다.

| 예제 파일 | 복사 대상 경로 | 설명 |
| :--- | :--- | :--- |
| `strategies/consensus_voting.py` | `strategies/` | 라운드별로 발언 순서와 프롬프트 지침이 동적으로 변경되는 합의 투표 토론 전략 |
| `host_tools/glossary.py` | `host_tools/` | 위험 등급(read)을 명시하여 사용자 확인 없이 자동 실행되는 호스트 도구 및 시스템 지침 주입 |
| `host_tools/ticket.py` | `host_tools/` | 위험 등급 미지정으로 실행 시 승인 카드가 표시되는 호스트 도구 및 작업 공간 파일 작성 |

복사 대상 경로는 프로젝트 루트 디렉터리 기준입니다. 디렉터리가 없을 경우 새로 생성합니다. 파일을 복사한 후 서버를 재시작하고, 호스트 도구는 에이전트 카드의 `도구` 설정 패널에서 활성화합니다.

자세한 가이드는 [플러그인 개발 설명서](../../user_manual/03-core/11-plugins.md)를 참조하십시오.

> [!WARNING]
> **플러그인은 메인 애플리케이션과 동일한 시스템 권한으로 실행되는 파이썬 코드입니다.** 플러그인 디렉터리에 파일을 배치하는 것은 파이썬 패키지를 시스템에 설치하는 것과 동일한 보안 위험을 갖습니다. 코드 내용을 철저히 검토하고 신뢰할 수 있는 코드만 추가하십시오.

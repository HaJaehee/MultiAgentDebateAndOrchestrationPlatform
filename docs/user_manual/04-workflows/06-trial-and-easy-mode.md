# 체험 서버와 비엔지니어 화면

> 상위: [워크플로우 개관](README.md) · 이전: [폐쇄망 배포](05-airgap-deployment.md)
>
> 관련 소스: `app/trial/` (체험 서버 모듈) · `app/easy/` (비엔지니어 쉬운 화면) · ADR-029

MADO는 단일 개발자나 관리자 전용 환경을 넘어, 사내 조직 구성원 누구나 별도의 클라이언트 설치 없이 웹 브라우저 접속만으로 멀티 에이전트 토론을 직접 경험하고 업무에 활용할 수 있도록 **체험 서버(Trial Mode)**와 **비엔지니어 화면(Easy Mode)**을 제공합니다.

---

## 1. 체험 서버 (다중 사용자 URL 체험 모드)

사내 서버나 가상 머신에 MADO를 기동해 두고, 사용자별 독립 세션과 인증 체계를 통해 토론 플랫폼을 서비스할 수 있습니다.

### 기동 설정

`conf.json`의 `trial` 설정을 활성화하고 외부 접속을 허용합니다:

```json
{
  "app": {
    "host": "0.0.0.0",
    "port": 8000,
    "llm_concurrency": 4
  },
  "trial": {
    "enabled": true,
    "templates_dir": "trial_templates",
    "notice": "본 체험 서버의 모든 세션은 사내 품질 개선 및 모니터링을 위해 관리자에게 공개될 수 있습니다."
  }
}
```

- `trial.enabled`: `true`로 설정하면 인증 토큰이 없는 일반 원격 접속자가 차단되지 않고 **체험 방문자 권한으로 자동 전환**됩니다.
- `app.llm_concurrency`: 사내 LLM 게이트웨이나 로컬 추론 서버의 허용 용량에 맞추어 동시 요청 수를 제한합니다 (`0`이면 무제한). 상한 초과 시 대기열(FIFO)에서 순차 대기하며 대기 순번 배너가 표시됩니다.

### 접속 권한 및 접근 제어

| 접속 유형 | 접근 허용 범위 |
| :--- | :--- |
| **서버 호스트 PC / 관리자**<br>(관리자 토큰 로그인) | MADO의 모든 기본 관리 기능(전문가 화면 `/`, 에이전트 구성 편집, API, 파일 다운로드) + `/trial/admin` 운영자 대시보드 |
| **체험 방문자**<br>(원격 일반 사용자) | `/trial` 및 `/trial/easy` 경로만 허용. 루트(`/`) 접속 시 체험 시작 페이지로 자동 리다이렉트되며, 관리자 화면, `/api/*` 엔드포인트, 작업 공간 파일 다운로드는 안전하게 차단됩니다. |

### 방문자 로그인 및 계정 체계

1. 웹 브라우저로 `http://<서버IP>:<포트>/`에 접속합니다.
2. **이름(또는 사번)과 4자리 이상의 PIN 번호**를 입력하여 로그인합니다. 최초 접속 시 PIN 번호를 한 번 더 확인 입력하여 즉시 등록됩니다.
3. PIN 번호는 단방향 `scrypt` 암호화 해시로만 안전하게 저장되며, 5회 연속 입력 실패 시 해당 계정은 15분간 자동으로 잠금 처리됩니다.
4. 로그인 세션 쿠키는 서버 서명 키(`data/trial/secret.key`)로 서명되어 위조가 불가능합니다.

### 템플릿 갤러리 및 토론 실행

- **공식 템플릿**: `trial_templates/*.json`에 정의된 사전 구성 시나리오(코드 리뷰, 기술 스택 선정, 보안 취약점 분석 등)가 갤러리 카드로 제공됩니다.
- **즉시 실행**: 원하는 템플릿을 선택하고 필요한 입력 변수만 입력하면 즉시 실시간 멀티 에이전트 토론이 시작됩니다.
- **개인 세션으로 복제**: 템플릿 기반 대화를 자신의 개인 세션으로 복제하여 참여 에이전트 목록, 프롬프트 지침, 토론 전략을 자유롭게 커스터마이징할 수 있습니다.
- **결과 확인**: 실시간 스트리밍 발언과 함께 최종 요약 및 "합의 사항 / 이견 쟁점" 결정 장부가 우선 표시됩니다.

### 자원 격리 및 보안 정책

- **도구 접근 제한**: 체험 방문자가 실행하는 템플릿 토론 에이전트는 `conf.json`의 모델 설정만 사용하며, `allowed_mcp_servers` 도구 권한은 기본적으로 비활성화됩니다. 다중 사용자가 접근하는 공용 서버 환경에서 파일 시스템 파괴, 샌드박스 남용, 자원 침범을 원천 방지하기 위함입니다.
- **세션 데이터 격리**: 방문자는 본인이 생성한 대화 세션만 조회할 수 있습니다. 타인의 세션 URL을 직접 입력하더라도 "존재하지 않는 대화"로 처리됩니다.
- **운영자 공지**: 시스템 관리자는 전체 체험 세션 내역을 열람 및 감사할 수 있으며, 이 사실은 화면 하단 공지(`trial.notice`)를 통해 상시 안내됩니다.

### 운영자 전용 대시보드 (`/trial/admin`)

관리자 토큰으로 로그인한 소유자는 `/trial/admin` 대시보드에서 다음 사항을 모니터링하고 제어할 수 있습니다:
- 템플릿별 실행 및 완료 통계, 평균 소요 시간
- 사용자 피드백 평가(👍/👎) 및 의견 모음
- 방문자 계정 목록, 접속 이력, PIN 초기화 및 잠금 수동 해제
- 등록된 템플릿의 JSON 문법 및 필드 유효성 점검
- 실시간 LLM 대기열 슬롯 현황

## 2. 비엔지니어 화면 (`/trial/easy`)

AI를 단순 단답형 챗봇으로만 접해본 입문자 및 비엔지니어 직군을 위한 사용자 친화적 전용 인터페이스입니다.

### 기획 의도 및 접근 방법

- **전문가 화면과의 공존**: 전문가 화면(`/`)과 체험 화면(`/trial`)의 모든 기능은 그대로 유지되며, 상단 헤더의 `쉬운 화면` 버튼을 통해 자유롭게 전환할 수 있습니다.
- **에이전트 동작 원리 교육**: 챗봇과 에이전트의 차이점, 에이전트의 4대 구성 요소(페르소나, 업무 지시서, 도구, 스킬), 그리고 에이전트가 **생각(Thought) → 행동(Action/도구) → 관찰(Observation)**의 순환 고리를 반복하며 과제를 해결하는 전 과정을 시각화합니다.

### 주요 화면 구성

| 화면 주소 | 명칭 | 기능 설명 |
| :--- | :--- | :--- |
| `/trial/easy` | **홈 (둘러보기)** | 챗봇 vs 에이전트 비교 인포그래픽, 에이전트 실행 루프 설명, 최근 내 실행 기록 및 등록된 에이전트 목록 |
| `/trial/easy/build` | **에이전트 만들기 (Builder)** | 도우미와의 대화형 인터뷰를 통해 원하는 에이전트 설계도(이름, 역할, 업무 지시서, 도구, 스킬)를 자동 생성 및 편집 |
| `/trial/easy/run` | **과제 실행** | 사용할 에이전트를 선택하고 과제 입력 (`?demo=1` 파라미터로 '자료 탐색가' 시연 즉시 실행 가능) |
| `/trial/easy/s/{id}` | **실행 현황** | 에이전트의 발언마다 생각·행동·관찰 단계가 실시간 카드 형태로 시각화. '전체 기록' 탭에서 도구 승인 및 추가 대화 가능 |

### 소유자(로컬)와 체험 방문자(원격)의 권한 차이

| 구분 항목 | 시스템 소유자 (로컬 호스트) | 체험 방문자 (원격 체험 사용자) |
| :--- | :--- | :--- |
| **생성한 에이전트** | `conf.json` 파일에 즉시 영구 저장되어 전문가 화면에서도 공용 사용 | 본인 계정 전용 '내 에이전트'로 DB에 저장 (`conf.json` 불변) |
| **사용 가능한 도구** | 설정된 모든 MCP 도구 (`tool_security` 정책 적용) | `filesystem` 도구만 안전한 읽기 전용(`read_only`)으로 제공 |
| **작업 디렉터리** | `workspace/easy` | `workspace/easy-guest` |
| **전문가 화면 접근** | 가능 (`/` 링크 상시 노출) | 불가 (링크 미노출 및 강제 리다이렉트) |

- 작업 디렉터리는 최초 진입 시 `app/easy/examples/`의 예제 파일(매출 CSV, 회의록 요약본, 고객 문의 데이터 등)이 자동 복사되어 초기화되므로, 즉시 파일 읽기 도구 실습을 진행할 수 있습니다.
- 빌더 도우미 및 세션 실행은 기본 오케스트레이터의 LLM 연결 설정을 공유하므로 복잡한 모델 설정 없이 즉시 동작합니다.

## 3. 통신 보안 주의사항

> [!WARNING]
> **HTTPS 미지원 주의**: 기본 HTTP 통신 환경에서는 네트워크 패킷 감청이 가능한 환경일 경우 방문자의 PIN 번호와 관리자 인증 쿠키가 노출될 수 있습니다. 방문자에게 타 시스템의 중요 비밀번호를 PIN으로 등록하지 않도록 안내하시거나, 보안이 요구되는 공용 네트워크에서는 Nginx/Caddy 등 리버스 프록시 앞단에서 SSL/TLS 종단을 구성하십시오.

# 워크플로우 개관

> 상위: [MADO 사용 설명서](../README.md) · 다음: [토론 한 턴의 생애주기](01-debate-turn.md)

[핵심 기술](../03-core/README.md) 섹션이 "각 구성 부품의 내부 동작 원리와 안전장치"를 다루었다면, 이 섹션은 **"실제 런타임에서 작업 흐름이 어떻게 연결되어 흘러가는가"**를 설명합니다. 시간의 흐름과 생애주기 순서로 구성되어 있습니다.

## 핵심 잠금(Lock) 규칙 요약

MADO 시스템에는 데이터 일관성과 런타임 안정성을 보장하기 위해 편집이 제한되는 두 가지 핵심 잠금 지점이 존재합니다:

| 잠금 대상 | 잠금 시점 | 잠금 사유 | 잠금 해제 방법 |
| :--- | :--- | :--- | :--- |
| **페르소나 · 구성 스냅샷** | 해당 대화의 첫 메시지 전송 시 | 이미 시작된 대화가 외부 설정 변경에 영향받지 않고 자기완결성을 유지해야 함 | 영구 잠금 유지 (필요 시 '설정 갱신' 버튼을 통해 인프라 설정만 최신화) |
| **로스터 편집 (전역)** | **어느 세션이든** 토론이 백그라운드 진행 중일 때 | 에이전트 풀 레지스트리는 프로세스 전체가 공유하므로 턴 진행 중 변경 차단 | 진행 중인 토론 턴이 완료되면 자동 해제 |

두 번째 잠금 규칙은 특히 주의해야 할 지점입니다. 다른 대화 세션에서 토론이 실행 중이라면 **현재 보고 있는 유휴 대화 세션에서도** 에이전트를 추가하거나 삭제할 수 없습니다. 프로세스 공유 풀을 교체할 경우 다른 세션에서 진행 중인 턴의 발언자 목록과 인프라 구성이 훼손될 수 있기 때문입니다.

단, 작업 공간 경로와 라운드 수, 토론 전략은 이 전역 잠금과 무관하게 개별 대화 세션 레벨에서 자유롭게 조정할 수 있습니다.

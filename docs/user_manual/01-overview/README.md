# 시스템 개요

> 상위: [MADO 사용 설명서](../README.md) · 다음: [기술 스택](01-tech-stack.md)

---

## 한 문장으로

**여러 LLM 에이전트가 서로의 발언을 이어받아 토론하고, MCP 도구로 사실을 검증하며,
합의된 결과를 실행 가능한 산출물로 합성하는 웹 애플리케이션.**

---

## 무엇이 다른가

LLM 하나에게 "이 시스템을 설계해 줘" 라고 물으면 그럴듯한 답이 하나 나옵니다.
검토한 사람이 없고, 코드가 실제로 도는지 확인한 적도 없습니다.

MADO 는 그 자리에 **역할이 다른 여러 에이전트**를 세웁니다.

```text
   사용자 요청
        │
        ▼
  ┌───────────────┐
  │ 오케스트레이터 │  목표를 분해하고 발언권을 배분
  └───────┬───────┘
          │
     ┌────┴────┬─────────┬─────────┐
     ▼         ▼         ▼         ▼
  아키텍트  엔지니어   리뷰어   (추가한 전문가…)
   설계      구현       검증
     │         │         │
     └────┬────┴─────────┘
          │  각 에이전트는 MCP 도구를 실제로 실행합니다
          │  (파일 읽기/쓰기, 코드 실행, git, 지식 그래프, 웹 fetch)
          ▼
  ┌───────────────┐
  │ 오케스트레이터 │  토론 전체를 종합해 최종 산출물 합성
  └───────┬───────┘
          ▼
   코드 · 문서 · 다이어그램
```

핵심은 **주장과 검증이 분리**된다는 것입니다. 엔지니어가 "이 코드는 동작합니다"
라고 하면, 리뷰어가 샌드박스 MCP 로 그 코드를 실제로 돌려 판정할 수 있습니다.

## 네 가지 설계 원칙

### 1. 설정이 곧 시스템 구성

에이전트, 모델, 엔드포인트, 자격증명, 도구 권한, 발언 순서, 토론 진영 —
전부 [`conf.json`](../02-getting-started/02-configuration.md) 에 있습니다.
새 전문가를 추가하는 데 소스 코드를 고치지 않습니다. 화면에서도 추가할 수 있고,
그 결과는 다시 `conf.json` 에 기록됩니다.

### 2. 시작한 대화는 자기완결적

첫 사용자 메시지가 기록되는 순간, 참여 에이전트의 **설정 전체**(페르소나, 모델,
엔드포인트, 키, 도구 권한)가 DB 에 스냅샷으로 굳고 잠깁니다. 그 뒤로 `conf.json`
에서 에이전트를 지우든 모델을 바꾸든, **그 대화는 시작할 때의 구성 그대로**
이어집니다. → [세션 생애주기](../04-workflows/02-session-lifecycle.md)

### 3. 없는 것을 지어내지 않는다

엔드포인트에 닿지 못한 에이전트의 차례는 `LLMUnavailableError` 로 실패하고,
토론 기록에 **연결 실패 사실이 그대로 남습니다.** 자리를 채우는 그럴듯한 문장을
만들지 않습니다. 최종 합성 프롬프트도 "이 에이전트는 발언하지 못했다" 를 알고
씁니다. → [LLM 통합](../03-core/03-llm-integration.md)

### 4. 폐쇄망에서 돈다

인터넷 없는 망에 반입할 것을 전제로 만들어졌습니다. 포터블 파이썬, `node.exe`,
오프라인 wheel, MCP 서버 설치본까지 한 번에 묶는 패키징 스크립트가 있고,
설정 파일의 모든 경로가 환경변수 치환을 지원해 개발 PC 와 배포 번들이 같은
파일 하나를 공유합니다. → [폐쇄망 배포](../04-workflows/05-airgap-deployment.md)

## 화면 구성

| 영역 | 하는 일 |
| :--- | :--- |
| **좌측 사이드바** | 과거 대화 목록, 새 대화 생성, 이름 변경, 삭제 |
| **상단 로스터 패널** | 에이전트 카드 (참여 토글, 드래그로 발언 순서, ⋮ 메뉴로 진영·비활성화·삭제), 라운드 수, 토론 전략, MCP 서버 상태 칩, 작업 공간 지정 |
| **중앙 토론 피드** | 사용자·오케스트레이터·에이전트 발언을 색과 아바타로 구분. MCP 도구 실행은 접이식으로. 끝난 발언은 세 줄로 접힘 |
| **산출물 뷰어** | 턴마다 최종 결론·종합 다이어그램·전문가 코드를 탭으로 쌓음. 원클릭 복사/다운로드 |
| **헤더 ⓘ 버튼** | 만든 사람·이메일·버전·라이선스를 모달로. 한 줄 복사 지원 |
| **페르소나 페이지** | `/personas/{session_id}` — 세션별 에이전트 인격 편집 |

# ADR-003. 도구는 MCP 서버로, 앱과 다른 프로세스에서 돌린다

> [ADR 목록](README.md) · 이전: [ADR-002](ADR-002-litellm-gateway.md) · 다음: [ADR-004](ADR-004-sqlite-persistence.md)

## 상태 (Status)

채택됨 · 2026-08-26 (초기 설계), 2026-08-31 원격 서버 지원 추가 · 관련: [ADR-005](ADR-005-long-lived-mcp-sessions.md), [ADR-010](ADR-010-host-defined-tool-scope.md), [ADR-016](ADR-016-per-workspace-mcp-runtime.md)

## 맥락 (Context)

- 에이전트가 주장을 검증하려면 도구가 필요합니다. 파일을 읽고 쓰고, 코드를 실행하고, 변경 이력을 보고,
  합의한 사실을 기억해야 합니다.
- 이 기능들을 앱 안에 파이썬 함수로 구현하면, 도구가 앱과 같은 프로세스, 같은 권한에서 돕니다. 샌드박스
  커널이 죽거나 무한 루프에 빠지면 앱도 함께 멈춥니다.
- 도구는 앞으로 늘어날 것이 분명했습니다(사내 문서 검색, 발표자료 편집 등).
- MCP(Model Context Protocol)는 공개 규격이고, 파일 시스템, 기억, 단계적 사고 같은 공식 서버와 여러 언어의
  SDK가 이미 있었습니다.

## 결정 (Decision)

MCP Python SDK로 **호스트**를 구현하고, 도구는 MCP 서버로 붙인다.

- 기본 도구 서버(filesystem, memory, git, sandbox)는 앱이 **자식 프로세스로 띄우고 stdio로 통신**한다.
- 도구 이름은 `서버__도구` 형식으로 이름공간을 붙이고, OpenAI 함수 호출 형식으로 바꿔 모델에게 넘긴다.
- 에이전트마다 `allowed_mcp_servers`를 두어, 허용된 서버의 도구만 모델에게 노출한다.
- MCP SDK 버전은 `>=1.29.0,<2`로 고정한다. 2.x에서 서버 API 이름이 바뀌어 동봉한 샌드박스 서버와 git 서버가
  기동하지 못한다.
- (2026-08-31 추가) 이미 떠 있는 서버는 주소로 붙는다. `command`와 `url` 중 하나만 적어야 하고, 둘 다 적거나
  둘 다 비우면 거절한다. 전송 방식은 Streamable HTTP를 먼저 시도하고 안 되면 HTTP+SSE로 한 번 더 시도한다.

## 결과 (Consequences)

**좋아지는 것**

- 도구가 앱과 다른 프로세스에서 돕니다. 커널이 죽어도 앱은 살고, 파일 시스템 서버는 허용 폴더 밖 경로를
  스스로 거부합니다.
- 도구를 추가하는 일이 설정에 실행 명령이나 주소를 적는 일이 되었습니다.
- Node로 만든 서버와 Python으로 만든 서버를 섞어 쓸 수 있습니다.

**치르는 비용**

프로세스 경계는 공짜가 아닙니다. 이 결정 이후 호스트가 떠안은 일이 계속 늘었습니다.

- 세션 수명 관리, 끊김 감지와 재연결 ([ADR-005](ADR-005-long-lived-mcp-sessions.md))
- 서버가 죽은 이유를 표준 오류에서 찾아 사람에게 보여 주기
- 응답하지 않는 서버와 지나치게 큰 결과에 대한 상한 ([ADR-014](ADR-014-tool-failure-is-observation.md))
- 프로세스를 번호가 아니라 핸들로 정리하기
- 여러 대화가 한 서버 프로세스를 공유할 때의 상태 격리 ([ADR-010](ADR-010-host-defined-tool-scope.md))
- 서버가 볼 폴더가 기동 시점에 고정되는 문제 ([ADR-009](ADR-009-refuse-cross-workspace-debates.md), [ADR-016](ADR-016-per-workspace-mcp-runtime.md))
- SDK 메이저 버전 호환을 직접 지켜야 함

**교훈**

"규격을 따르는 외부 서버를 붙인다"는 결정은 기능 구현의 부담을 덜어 주는 대신, **분산 시스템의 부담**을
가져옵니다. 프로세스가 하나 늘 때마다 실패 방식도 하나씩 늘어난다는 점을 처음부터 계산에 넣어야 합니다.

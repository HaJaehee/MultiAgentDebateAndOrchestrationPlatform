# CSV 요약 지침

데이터를 바탕으로 토론을 진행하기에 앞서, 열의 의미나 값의 범위를 자의적으로 추정하지 마시고 본 스킬의 스크립트를 실행하여 실제 데이터 구성을 먼저 확인해 주십시오.

## 실행 방법

1. (선택 사항) 특정 파일만 선별하여 분석하려면 작업 공간 루트에 `csv-profile.targets.txt` 파일을 생성하고, 한 줄에 하나씩 작업 공간 기준 상대 경로를 기재합니다. 해당 파일이 없으면 작업 공간 하위의 모든 CSV 파일(최대 20개)을 대상으로 분석을 수행합니다.
2. `scripts/profile_csv.py` 스크립트를 실행합니다. 본 스킬을 호출(`skills__load_skill`)한 반환 결과의 말미에 작업 공간으로 복사된 스크립트 경로가 안내되므로, 해당 경로를 `run_python_file` 도구의 `file_path` 인자로 전달하시면 됩니다. 별도의 추가 인자는 전달받지 않습니다.
3. 분석 결과는 표준 출력으로 표시되며, 동일한 내용이 작업 공간 내 `csv-profile.md` 파일로도 자동 저장됩니다.

## 결과 활용 지침

- 발언 본문에 요약 표 전체를 기재하기보다는 핵심 판단에 필요한 열만 선별 인용하시고, 전체 상세 내용은 `csv-profile.md` 파일을 참조하도록 안내해 주십시오.
- 우선적으로 검토할 항목: 결측치(빈 값)가 다수 존재하는 열, 숫자형이어야 하지만 단위나 특수기호 혼입으로 문자형("글")으로 판정된 열, 헤더 열 수와 실제 데이터 열 수가 일치하지 않는 행.
- 본 스킬을 호출하였으나 실행 도구(`run_python_file`)가 부재하다는 안내가 반환된 경우, 임의로 데이터를 추정하지 마시고 실행 권한을 보유한 에이전트에게 실행 및 요약을 요청하십시오.

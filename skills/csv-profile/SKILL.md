# CSV 요약

데이터를 두고 토론하기 전에, 열의 의미나 값의 범위를 짐작하지 말고 이 스킬의 스크립트로 실제 모양을
먼저 확인하세요.

## 실행

1. (선택) 특정 파일만 보려면 작업 공간에 `csv-profile.targets.txt` 를 만들고, 한 줄에 하나씩 작업 공간
   기준 경로를 적습니다. 이 파일이 없으면 작업 공간 아래의 CSV 를 모두(최대 20개) 봅니다.
2. `scripts/profile_csv.py` 를 실행합니다. 이 스킬을 불러온 결과 끝에 작업 공간으로 복사된 경로가 있으니,
   그 경로를 `run_python_file` 의 `file_path` 로 넘기면 됩니다. 인자는 받지 않습니다.
3. 결과는 출력과 함께 작업 공간의 `csv-profile.md` 로도 저장됩니다.

## 결과를 쓸 때

- 발언에는 표 전체를 옮기지 말고 판단에 필요한 열만 인용한 뒤, 전체는 `csv-profile.md` 를 가리키세요.
- 먼저 짚을 것: 빈 값이 많은 열, 숫자여야 하는데 "글"로 잡힌 열(단위·기호가 섞임), 열 수가 머리글과 다른 행.
- 이 스킬을 불러왔는데 실행 도구가 없다는 안내가 나오면, 값을 추측하지 말고 실행 도구를 가진 에이전트에게
  요약을 부탁하세요.
